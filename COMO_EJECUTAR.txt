 CÓMO EJECUTAR - PPAI Bolsines (DSI 2026) - CU 28 Registrar recepción de bolsín
 3K5 · Grupo 06 · Última actualización: 10/11/2026
==============================================================================

Son dos programas que corren al mismo tiempo, cada uno en su terminal:
  - BACK  (Java / Spring Boot) en http://localhost:8080. Trae su base de datos H2 adentro:
          no hay que instalar ninguna base ni Docker.
  - FRONT (React / Vite)       en http://localhost:3000. Es lo que se abre en el navegador.
Los comandos de este archivo son para Windows (PowerShell). Para Mac/Linux, ver la sección 8.

------------------------------------------------------------------------------
 1. QUÉ HAY QUE TENER INSTALADO (una sola vez)
------------------------------------------------------------------------------
  a) Git                      https://git-scm.com/downloads
  b) JDK 21. Tiene que ser el 21: con versiones más nuevas Lombok no compila.
     Recomendado: Eclipse Temurin 21 (https://adoptium.net). En el instalador, marcar
     "Set JAVA_HOME variable".
  c) Node.js 22 LTS (o cualquier versión 20.19 o superior)   https://nodejs.org
  d) Opcional: IntelliJ IDEA (sección 7).
  Maven NO hace falta: el proyecto trae el wrapper (mvnw), que lo descarga solo.

  Para comprobarlo, abrir una terminal nueva y escribir:
     java -version          -> tiene que decir 21.x
     node -v                -> v22.x (o v20.19 o superior)
     git --version

------------------------------------------------------------------------------
 2. BAJAR EL PROYECTO (una sola vez)
------------------------------------------------------------------------------
     git clone <URL-del-repositorio-del-grupo>
     cd ppai-bolsines

  Si te pasaron el .zip, descomprimilo y entrá a la carpeta ppai-bolsines.

------------------------------------------------------------------------------
 3. LEVANTAR EL BACK (terminal 1)
------------------------------------------------------------------------------
     cd back
     .\mvnw.cmd clean install        # la primera vez tarda: baja las dependencias y corre las 25 pruebas
     .\mvnw.cmd spring-boot:run

  Está listo cuando aparece:
     Started BolsinesApplication in X seconds
  Para comprobarlo, abrir http://localhost:8080/actuator/health. Tiene que decir "UP".

  Si tenés más de un JDK instalado (o "java -version" no dice 21), antes de los comandos apuntá
  esa terminal al 21 (cambiá la ruta por la de tu JDK 21). Esto vale sólo para esa terminal:
     $env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-21.0.x-hotspot"
     $env:Path = "$env:JAVA_HOME\bin;$env:Path"
  Para que quede fijo para tu usuario:
     [Environment]::SetEnvironmentVariable("JAVA_HOME", "C:\ruta\al\jdk-21", "User")
  Después cerrá la terminal y abrí una nueva.

  La base de datos se crea sola en back\data. Cada vez que el back arranca, se borra y se
  vuelve a cargar con los datos de prueba (back\src\main\resources\data.sql). Por eso la
  demo siempre empieza igual.

------------------------------------------------------------------------------
 4. LEVANTAR EL FRONT (terminal 2)
------------------------------------------------------------------------------
     cd front
     npm ci                          # sólo la primera vez (o si cambia package-lock.json);
                                     # instala exactamente las versiones del package-lock.json
     npm run dev

  Abrir http://localhost:3000 en el navegador.
  El front le reenvía al back todo lo que va a /api. Por eso el back tiene que estar levantado
  antes de usar la pantalla.

 9. PROBLEMAS CONOCIDOS Y SOLUCIÓN
------------------------------------------------------------------------------
  - "ExceptionInInitializerError ... EndPosTable" al compilar:
      Maven está usando un JDK distinto del 21. Configurar JAVA_HOME (paso 3).
  - ".\mvnw.cmd no se reconoce":
      Estás en la carpeta equivocada; tenés que estar dentro de back.
  - "Remote host terminated the handshake", "SSL peer shut down" o dependencias en rojo en
    IntelliJ:
      El antivirus (por ejemplo, el escaneo HTTPS de AVG) corta la descarga desde Maven
      Central. Revisar la conexión, el proxy y los certificados; después repetir la compilación y
      recargar Maven en IntelliJ.
  - "npm no se puede cargar porque la ejecución de scripts está deshabilitada":
      En PowerShell, una sola vez:
        Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
      O usar npm.cmd en lugar de npm.
  - "Port 8080 was already in use" (o el 3000):
      Quedó un back (o un front) corriendo. Cerrar esa terminal. Si sigue ocupado:
        netstat -ano | findstr :8080        -> anotar el PID de la última columna
        taskkill /PID <PID> /F
  - El front dice "No se pudo comunicar con el servidor":
      El back no está levantado, o todavía está arrancando.
  - Los datos "volvieron" después de reiniciar: es normal, porque la base se recrea en cada
      arranque (ver "Persistencia entre reinicios" en el paso 5).
  - Una tilde llega mal al back al probar la API con curl en Windows (400 "Invalid UTF-8"):
      es la consola, no el back. Desde el front no pasa.
  - No hace falta Docker ni PostgreSQL: la base es H2 y viene dentro del back.
